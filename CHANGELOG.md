# Changelog

## [1.6.3] - 2026-11-10

- Updated Bootayar startup icon, About window, and indigo/violet theme.
- Poll `launchctl list` every 4s while the Agents list is active.
- Hardened shell quoting and plist label checks for privileged operations.

## [1.6.2] - 2026-10-20

- Multi-trigger editor for daily, weekly, monthly, interval, and `WatchPaths` rules.
- Preserve custom plist keys when saving from the form editor.

## [1.6.1] - 2026-07-30

- Added Crontab manager for user and `/etc/crontab` jobs.
- Added Homebrew service controls and sidebar module toggles.

## [1.6.0] - 2026-07-02

- Added local TCP Services scanner and Docker container port detection.
- Added XML plist editor, import, and job cloning.
